# 個人用ダッシュボード ── 話す・調べる・整理する

> 「やるべきことを忘れる」「調べたことが散らばる」「日々の振り返りが続かない」  
> ──そんな自分の小さな不便を、生成AIとの対話だけで解決するアプリを作りました。

##　使い方

`index.html` をブラウザ（Chrome推奨）で開くだけで動作します。インストール不要。

- 音声入力は Chrome の Web Speech API を使用しています
- データはブラウザの localStorage に保存されます（リロードしても消えません）

---

## 💡 何を作ろうと思ったか・なぜか

### 課題意識

自分の日常には、こんな「小さな不便」がいくつもあった。

- 調べたことをどこに書けばいいか迷い、結局忘れる
- 長期目標と今日のタスクがつながって見えない
- 1日の終わりに「何をしたか」を振り返る習慣が続かない
- メモを取ること自体が面倒で、思考が揮発する

これらはバラバラに見えて、根っこは同じだと気づいた。  
**「インプットと行動管理が一か所に集まっていない」** のが問題だった。

### 解決のアイデア

「話しかけるだけで記録できて、目標から今日のタスクまでつながって見えるダッシュボード」を作ることにした。  
バイブコーディングの強みである「AIとの対話でアイデアを形にするスピード感」を活かして、1〜3日で動くものを目指した。

## 🛠️ 機能一覧

| 機能 | 説明 |
|---|---|
| **目標ツリー** | 長期目標 → 今年 → 今月 → 今週を階層表示。つながりが一目でわかる |
| **今日のタスク** | チェックボックスで完了管理。音声入力対応 |
| **知識メモ帳** | タイトル・内容・複数ラベルでカード保存。日時順／あいうえお順で並び替え、AND絞り込みに対応 |
| **思考メモ** | 自由記述＋音声入力。過去のメモを一覧表示 |
| **日報（3ステップ）** | 完了・未完了タスクを自動入力 → 自由記述 → 明日のタスク登録 → 保存・コピー |
| **起動時の進捗確認** | 未完了タスクをバナーで通知 |
| **17時の自動日報** | 17時になると日報ページが自動で開く |

## 🤖 生成AIとのやり取り

### 開発の進め方

このアプリはコードを1行も手書きせず、**Claudeとの対話だけで作った**。  
手順はシンプルで、以下のサイクルを繰り返した。

```
① 「不便に思っていること」を話す
② Claudeが機能に翻訳してくれる
③ 「こうじゃなくてこう」と修正指示
④ 動くコードが出てくる
⑤ また①へ
```

### 実際のプロンプトの流れ（抜粋）

**最初の設計段階**
```
「やること、調べること、ネタの文字起こし、長期・短期の目標管理、
 やるべきことをすぐ動けないことが不便。これをまとめて解決したい。」
```
→ Claudeが機能を整理・提案し、3ページ構成に絞り込んだ。

**機能の詳細化**
```
「マイクで話した内容を別ページに蓄積して、
 ラベルでフィルタリングしたい。政治家ラベルだけ見るとか。」
```
→ 知識メモ帳のカード＋タグ設計が決まった。

**UX改善の指示**
```
「ラベルの入力と貼る場所は別がいい。
 エンターでどんどん追加していく感じにして。」
```
→ 入力欄とチップ表示エリアを分離。

**日報の設計**
```
「桜井政博氏の日報フォーマットを参考にしたい。
 自分で書き込めるようにしつつ、
 タスクは自動入力されていてほしい。
 入力が終わったら明日のタスクを作る流れを作りたい。」
```
→ 3ステップの日報フローが生まれた。

### 工夫したやり取り

- **「なぜそれが不便か」を先に話す**ことで、Claudeが適切な機能に翻訳してくれた
- 「こういうイメージ？」とClaudeが確認してきたとき、**YesかNoを即答**することでブレが減った
- コードを見ずに「動いた・動かなかった」だけをフィードバックしても修正できた

## 🪨 詰まったところとどう乗り越えたか

### ラベルのUI設計

**問題：** 知識メモのラベル入力で、「1つの入力欄に複数タグをどう追加するか」のUIが最初うまくいかなかった。最初はカンマ区切り入力を試みたが、直感的でなかった。

**解決：** Claudeに「入力欄とラベルを貼る場所を分けて、Enterでどんどん追加していく感じにしたい」と自分のイメージを言葉にして伝えた。するとタグチップUIとして実装してもらえ、使いやすくなった。

→ **教訓：「こうしたい」ではなく「こういう体験にしたい」を伝えると精度が上がった。**

## 🔭 次にやるなら何を変えるか

### 1. AI要約機能の追加
知識メモ帳で「これについて調べて」と話すと、AIが自動でまとめてカードを作る機能。今回はAPI費用の問題でスキップしたが、Gemini APIの無料枠を使えば実現できる。

### 2. UIの改善
目標ツリーやカード表示をより視覚的に洗練させたい。アニメーションや色のコントラスト調整など。

### 3. ラベルの多次元可視化
「重要度」「面白さ」など尺度のあるラベルは、数直線・平面・立体で表現したい。例えば「重要度×緊急度」の2軸マトリクスでカードを配置するなど。

### 4. クラウド保存
現在はlocalStorageのみのため、デバイスをまたいで使えない。Supabase等を使ってクラウド同期したい。

### 5. スマホアプリ化
音声入力を使う場面はスマホのほうが自然。PWA対応またはReact Nativeへの移植を検討したい。
